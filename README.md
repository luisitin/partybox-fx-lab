# PartyBox FX lab

Public workshop for TV and phone visual effects for party games: single-file HTML pages, original code-made art. Each job lives in jobs/<ID>-<slug>/; earlier rounds to build on are in start/.

- RUN-ALL.md: the message that starts an agent working the queue.
- RULES.md: binding rules for every job.
- JOBS.md: the queue.
- CLAIMS.md: who is working on what.
